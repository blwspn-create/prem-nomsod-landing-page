# 🥛 บาบี้ นมสด (Babi Nomsod) - Landing Page

เว็บไซต์ Landing Page สไตล์คาเฟ่และร้านนมสด สำหรับร้าน **"บาบี้ นมสด"** ออกแบบให้มีความสวยงาม อบอุ่น ทันสมัย น่ารับประทาน และรองรับการแสดงผลบนทุกอุปกรณ์ (**Mobile-Responsive 100%**)

---

## 🌟 จุดเด่นของเว็บไซต์ (Features)
- **Responsive Web Design:** ใช้งานได้สมบูรณ์แบบทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
- **Interactive Menu Filter:** ระบบกรองหมวดหมู่เมนูแนะนำ (เครื่องดื่มนมสด, ปังปิ้งเตาถ่าน, บิงซู, ของทานเล่น)
- **Image Lightbox Modal:** คลิกดูรูปเมนูและบรรยากาศร้านขนาดใหญ่แบบเต็มจอ
- **Direct Social Integration:** ปุ่มลิงก์เชื่อมต่อไปยัง **Facebook เพจ บาบี้ นมสด**, เบอร์โทรศัพท์ และ Google Maps
- **Night Vibe Cafe Theme:** โทนสีอบอุ่น (Amber, Bread Toast, Pastel Blue) พร้อมภาพถ่ายบรรยากาศจริง

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5** โครงสร้างเว็บมาตรฐานและ Semantic Elements
- **Tailwind CSS (CDN)** จัดการเลย์เอาต์ ออกแบบ UI และเอฟเฟกต์ Transition / Hover
- **Google Fonts ('Prompt')** ฟอนต์ภาษาไทยสไตล์โมเดิร์น อบอุ่น สบายตา
- **Font Awesome 6 (CDN)** ไอคอนตกแต่งคุณภาพสูง

## 📁 โครงสร้างโปรเจกต์ (Project Structure)
```
ร้านนม/
├── index.html            # โค้ดหน้าเว็บ Landing Page หลัก
├── logo.png              # โลโก้ร้าน บาบี้ นมสด
├── README.md             # เอกสารอธิบายโปรเจกต์
├── บรรยากาศในร้าน/       # รูปภาพบรรยากาศร้าน แสงไฟยามค่ำคืน และมุมถ่ายรูป

```

---

## 🚀 วิธีการเปิดใช้งาน (Getting Started)
1. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari)
2. หรือใช้ Extension เช่น Live Server บน VS Code เพื่อรันในเครื่อง
